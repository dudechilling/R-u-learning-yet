Beginner · Descriptive statistics

1. Explore a histogram

  1. Ask: What does the distribution of eruption durations look like?
  2. Check: faithful$eruptions contains numerical durations, measured in minutes. The observations come from a built-in example dataset.
  3. Copy and run: Use the code below. RStudio should display a histogram in the Plots pane.
R code: built-in faithful data
data(faithful)
durations <- faithful$eruptions
histogram <- hist(durations, breaks = "Sturges",
  main = "Eruption durations", xlab = "Duration (minutes)")

  1. Observe: The bars count observations in duration intervals. There are 272 recorded durations. Describe peaks, gaps and spread before making a claim.
  2. Experiment: Change breaks = "Sturges" to breaks = 12. Re-run the code. Bin widths change the appearance but not the underlying measurements.

Core · Statistical inference

2. Estimate an average with an interval

  1. Ask: How can I estimate a population mean when its standard deviation is unknown?
  2. Check: A one-sample Student t interval requires a suitable sampling design and independence assumptions. With only five observations, distributional assumptions need careful attention.
  3. Copy and run: The numbers are invented for practice, not evidence about a real population.
R code: five synthetic measurements
values <- c(4, 6, 8, 9, 13)
interval <- t.test(values, conf.level = 0.90)$conf.int
round(interval, 2)

  1. Observe: R should print approximately 4.77 and 11.23, the interval endpoints in the same units as the measurements.
  2. Interpret: In repeated valid sampling, this construction covers the population mean in 90% of intervals. It does not mean a fixed population mean has a 90% probability of being inside this realized interval.
  3. Experiment: Change conf.level = 0.90 to 0.95. The interval should widen. Changing a confidence level cannot correct biased sampling.

Read the verified confidence-interval reference.
