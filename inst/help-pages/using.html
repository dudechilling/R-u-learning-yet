Use the local library

Find a method

Run ru_find("How do I create a histogram?"). Give the distribution, event boundary or study design when it matters. For a mean confidence interval, state whether population standard deviation is known. An underspecified or contradictory question can return no match. Search ranks compatible references; it does not solve an assessment or invent missing observations.

Read and edit native R

Read the conditions before copying code. Use ru_edit("histogram", mode="quick") for an editable compact example. Inspect the example in the Source editor, replace the named inputs, then run it. Use ru_edit("histogram", mode="quick", open=FALSE) to create the script without opening the editor.

Tutorials

Open two guided tutorials for a histogram and a one-sample mean confidence interval. Each has a runnable example, expected outcome and interpretation. If you prefer R commands, ru_guide("histogram") and ru_guide("mean_confidence_interval") open existing local walkthroughs. Some older guides still require review; their availability does not validate every study design.

Histogram reference and Mean confidence interval reference are local pages. Browse references includes older help entries with their status notices.

Interpret results

Distinguish a description of the data from an estimate about a population. Check units, independence, sampling design, missingness and model assumptions. A p-value is not the probability that a hypothesis is true. A narrow confidence interval does not correct biased sampling. A fitted relationship alone does not establish causation.
