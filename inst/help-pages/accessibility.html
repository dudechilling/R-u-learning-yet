Accessibility and help

Keyboard

Press Tab and Shift+Tab to move between links, Copy controls and scrollable code. Use Enter to activate links and buttons. Use Space or Enter on expandable headings. A visible outline marks keyboard focus. Scrollable code has its own focus stop.

Copy fallback

Copy does not execute code. If clipboard access is unavailable, select the code and use Ctrl+C on Windows or Linux, or Command+C on macOS. The status message reports the result. The editor remains under your control.

Text and pane size

Enlarge text using the IDE or browser controls. Local figures include text alternatives and full-size links. Method meaning does not depend on colour alone. Automated browser checks are not a substitute for testing the actual RStudio interface or assistive technology.

Console alternative

Use ru_text("mean") for short text, help(package="rulearn") for installed help, and ru_home(open=FALSE) to obtain the local HTML path without opening a window.

Report a reproducible problem

Record the package version, R version, operating system, command and observed result. Remove personal data before sharing a report. Use packageVersion("rulearn") and sessionInfo(). There is no remote support or telemetry service inside the package.

Current verification limits

Real Windows RStudio attachment, keyboard, clipboard and screen-reader acceptance remain unverified for this local candidate. No screenshot or full WCAG conformance claim substitutes for those checks.
