Start here

R is the calculation language. RStudio is an optional interface with a Console, a script editor and a Viewer. The Console runs commands. A script saves them. This library explains methods in the Viewer.

Attach and browse

Run library(rulearn). In a supported interactive RStudio session, the local home opens once when the package attaches. Run ru_home() to reopen it. Without RStudio, use ru_text("mean") or help(package="rulearn").

A first original R example

The numbers below are invented measurements for practice. They are not observations from a real study. Create an object called x, then calculate its arithmetic mean.

Native R
x <- c(4, 6, 8, 9, 13)
mean(x)
ru_find("How do I create a histogram?")

The mean is 8. This describes these five values. It does not establish a population mean, a treatment effect or a causal conclusion. Replace x only after checking the measurement units and missing values. A histogram describes the distribution, not the truth of a model.
