# How do I distinguish nominal, ordinal, interval and ratio scales?

## Immediate answer

Nominal values name categories; ordinal values order categories. Interval measurements have equal differences but no meaningful zero ratio; ratio measurements also have a meaningful zero. Numbering categories 1–7 does not itself make the spacing between opinions equal.

## Exam answer pattern

First identify what the variable actually records, then whether its values can be ordered, subtracted meaningfully, or compared as ratios. For an ordered agreement response, explain why rank order is known but equal spacing is an additional assumption.

## What to check

- A code such as 1, 2 or 3 can name categories, not a measurement.
- Temperature in Celsius is interval, while elapsed time and length are ratio.
- Classify the construct, not the storage type R reports.

## Interpret your results

Choose summaries and graphs that match the scale: counts for nominal categories, ordered counts/medians for ordinal ratings, and means/SD for quantitative measurements when their assumptions make sense.

## Learn more

Treat averaging Likert-style ratings as a modeling decision, not proof that the response scale is interval. Explain the assumption if you make it.
