# What is an event in probability?

## Immediate answer

An event is a set of outcomes from a defined sample space. It has probability between zero and one; the probability of the entire space is one.

## Exam answer pattern

Define the experiment, sample space and which outcomes form event A. Explain whether elementary outcomes are equally likely before assigning probabilities.

## What to check

- An event may contain more than one outcome.
- Do not assume equal probabilities merely because outcomes can be listed.

## Interpret your results

Event probability describes the chance under a model, not a certain future result.

## Learn more

For a fair die there are six equally likely outcomes; actual fairness is an assumption requiring evidence.
