# L2 W0 Learning curriculum and assessment contract
Status: DRAFT, not an accepted curriculum. All 40 mandatory outcomes across ten blocks remain in ru-curriculum.csv. Three lessons are an internal G2 gate, not final scope.

## Lesson 1: Console, terminal and errors (ORI-01, ORI-02)
Prerequisites: none. Explain R runtime versus RStudio IDE; Console accepts R, terminal accepts shell, Source stores scripts. Worked Console expression `2+3` yields 5. Shell example `Rscript --version` never goes in R Console. Complete `sum(c(2, ___))`. Independent transfer: sort unfamiliar code/shell instructions by surface, run a new expression and repair an unmatched quote or parenthesis. Feedback diagnoses shell-in-Console, copying prompts, and parser errors. Assess both execution and explanation, not a memorized string.

## Lesson 2: Source and reproducibility (ORI-03, R-01; introduce R-02)
Prerequisite: ORI-02. Worked saved script `counts <- c(6,8,10); print(mean(counts))` yields 8. Complete a different vector's mean; then create a project and Source script for unfamiliar values, restart R, source it and reproduce the output. Explain saved file versus lost workspace object, assignment versus equality, named arguments and function help. Feedback handles undefined object, mistaken equality, editor-only execution and unwarranted rejection of valid assignment syntax. Embedded exercise success cannot substitute for observed Windows Source/Console transfer.

## Lesson 3: Inspect before summaries (R-03, R-04, DAT-01)
Prerequisite chain: ORI-03 and R-01/R-02, followed by R-03 and R-04. Worked data `data.frame(site=c("N","N","S","S"),temp_c=c(13,NA,18,20))` has one missing observation and observed-case mean 17 degrees C. Explain `str()`, `is.na()`, data types, observational unit and explicit `na.rm=TRUE` exclusion. Partly supplied count/summary; independent transfer imports another *bundled* CSV and documents type, units and missingness. This fixture is not yet authored. Diagnose `x==NA`, NA-to-zero substitution, numeric identifiers misread as measurements, and unverified import types. Do not imply DAT-02/DAT-03 or histogram outcomes are complete.

## Validation, review and boundaries
Every future outcome needs versioned IDs, worked/partial/independent tasks, accepted equivalent solutions, at least two seeded misconceptions, interpretation, transfer and educational review. Use learnr rather than a custom interpreter. Progress states introduced/practised/performed_independently require actual evidence; hints and elapsed time cannot promote competence. Learners may override entry placement (novice; statistics-first; R-first). Local answers are learning evidence, not secure grades. Four later capstones cover data visualization, paired-vs-independent inference, model diagnostics and reproducible research handoff. G1 requests: L1 launch/state/cache and content IDs; L3 statistical review; L4 accessible rights-cleared assets and reference mapping; L5 independent negative/GUI/human acceptance tests. No bulk authoring before G1/G2.
