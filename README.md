# R-u-learning-yet

A searchable bank of worked RStudio problems. Start with the question you need to solve, follow the numbered steps, run the script, and interpret the result.

## Use in RStudio

1. Open **File > New Project > Version Control > Git**.
2. Clone `https://github.com/dudechilling/R-u-learning-yet.git`.
3. Browse `problems/` or search the repository using **Ctrl+Shift+F**.
4. Open the matching script in `R/`, select a line, and press **Ctrl+Enter** to run it.
5. Replace the example values with your own, then check units, missing values, and assumptions.

A searchable Quarto website can be built from the same pages. All datasets included here are illustrative.
